# Amazon Sales Performance Dashboard

An executive-level Power BI analytics solution developed to evaluate global sales performance, track profitability drivers, and optimize logistics metrics across $12.64M in Amazon order data.

![Dashboard Preview](Amazon_Sales_Dashboard.png)

## Technical Pipeline
* **Excel:** Initial dataset prep, field structural validation, and schema verification.
* **Power BI & DAX:** Star-schema data modeling, custom explicit measures (Profit Margin %, Revenue, AOV), dynamic cross-filtering, and visual presentation.
* **GitHub Repository:** Version control, project documentation, and visual asset hosting.

## Key Business Insights
* **Geographic Drivers:** The APAC market generates **$3.59M in sales**, leading global volume ahead of the EU ($2.94M) and US ($2.36M).
* **Profitability Focus:** The global portfolio maintains an **11.61% profit margin**, yielding $1.47M in total profit on an Average Order Value (AOV) of $504.99.
* **Logistics Optimization:** High shipping overhead in lower-volume regions like Canada and Africa—specifically across Same Day fulfillment—presents an immediate operational margin optimization opportunity.
